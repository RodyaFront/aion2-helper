# Стереотипные визуальные решения AI-агентов

Чеклист того, что агенты по умолчанию клепают в UI. В этом проекте такие приёмы **запрещены**; см. также `DESIGN_SYSTEM.md` и токены в `app/assets/css/tokens.css`.

## Палитры и атмосфера

| Клише | Почему плохо | Что делать вместо |
| --- | --- | --- |
| Фиолетовый / indigo glow на тёмном | «AI SaaS»-дефолт 2023–25 | Статусный цвет только у сигнала (border, chip, timer) |
| Несколько `radial-gradient` «атмосферы» на фоне | Декор без смысла, шум | Плоский или один слабый линейный фон |
| Glassmorphism: `backdrop-filter` + полупрозрачный sticky | Размывает текст, тормозит Electron | Непрозрачный header, чёткая линия |
| Soft glow / neon на кнопках и карточках | Декоративный «вау», не статус | Без `box-shadow` glow; статус = цвет бордера и текста |
| Mint CTA + gold reward на каждой карточке | Стена одинаковых CTA | CTA по стейту: громко только idle/ready |

## Форма и хром

| Клише | Почему плохо | Что делать вместо |
| --- | --- | --- |
| `border-radius: 999px` / pill everywhere | Мягкий «продуктовый» вид | Малый радиус (`--radius-sm` / `--radius-md`) |
| Многослойные тени на каждой карточке | Мыло, одинаковая глубина | Одна плоская тень или только border |
| Бейджи-«капсулы» с мягкой заливкой | Визуальный шум | Компактный chip с border, без ореола |
| Градиентные primary-кнопки | Шаблон midjourney-dashboard | Плоская заливка одного токена |
| Бренд-ромб / орб с `box-shadow` glow | Пустой «логотип агента» | Текст марки без декоративного маркера |
| Inter / system stack как «дизайн» | Нейтральная безликость | Явные display/mono стеки (уже в токенах) |

## Движение и стейты

| Клише | Почему плохо | Что делать вместо |
| --- | --- | --- |
| Pulse/glow анимация на всём urgent/ready | Отвлекает, seizure-adjacent | Лёгкий breathe **только** border или opacity chip; уважать `prefers-reduced-motion` |
| Hover = brightness filter | Ломает каскад, выглядит дёшево | Явные hover-токены background/border/color |
| Одинаковый layout для 1 и 24 карточек | Пустой угол / стена | Focus-grid для узких фильтров |

## Контент и копирайт UI

| Клише | Почему плохо | Что делать вместо |
| --- | --- | --- |
| Эмодзи в chrome | Игрушечность | Только текст / kbd |
| «Beautiful modern dashboard» секции | Вода | Одна работа на секцию |
| Контрастив «это не X, это Y» в copy | См. global rule | Прямая формулировка |
| AI-типографика: `—` `–` `«»` `…` `→` в UI | Выглядит как сгенерированный текст | Обычный `-`, `"..."`, `...`, слова вместо стрелок |
| Жаргон (SFX, TTS, Piper, sidecar, Electron, field-босс, тумблер) | Игрок не обязан знать стек | Звук, голос, приложение, полевой босс, переключатель |

## Рефакторинг в AionBossTracker (применено)

- Убраны ambient radial glows и header blur.
- Кнопки primary/ready — плоские, без градиентов и hover-glow.
- Ready/urgent: без box-shadow pulse; chip opacity + border.
- Brand mark без светящегося ромба.
- Радиусы и тени урезаны; карточки опираются на ровный 1px border (цвет по статусу).
- Persist таймеров: файл в `userData` + фиксированный localhost-порт (не origin от `listen(0)`).

При добавлении UI: сверься с таблицами выше до merge.
